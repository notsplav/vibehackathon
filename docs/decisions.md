# Принятые решения и отступления от ТЗ

Сюда записываются решения, которые уточняют или меняют [ТЗ](../tech.md), а также изменения общих контрактов (API, схема SQLite, вердикты, `blockId`). Отступление из-за ограничений API или браузера записывается только после того, как проблема воспроизведена.

Новые записи добавляются сверху.

## Решения

### 2026-10-25 — Уточнения контракта в `shared/contract.ts`

- **Что изменено:** ТЗ (раздел 6) описывает контракт примерами; в коде он зафиксирован типами `shared/contract.ts`. Уточнения сверх ТЗ:
  - типы блоков: `title`, `subtitle`, `heading` (h2–h6 внутри статьи), `paragraph`, `list_item`, `quote`, `caption`;
  - статусы claim: технические `queued`, `checking`, `failed`, `not_checked`, плюс `checked` (вердикт получен) и `opinion` (оценочное суждение, не проверяется и не входит в знаменатель статистики). Вердикт хранится отдельно в поле `verdict`;
  - у свидетельства поле `grounding` ссылается на аннотацию Gemini; источник без неё не принимается;
  - у `extraction` при `status: "failed"` есть `error.code`: `not_article`, `empty_page`, `low_confidence`.
- **Почему:** нужны однозначные значения для расширения, сервера и SQLite.
- **Кто принял решение:** владелец репозитория (единственный разработчик на момент записи).
- **Затронутые контракты:** API (типы `ExtractedArticle`, `Claim`, `AnalysisState`).

### 2026-10-25 — Файл ТЗ называется `tech.md`

- **Что изменено:** техническое задание лежит в `tech.md` (в `CLAUDE.md` раньше упоминался `ТЗ.md`). Ссылка в `CLAUDE.md` исправлена.
- **Почему:** латинское имя файла удобнее в командной строке и ссылках.
- **Кто принял решение:** владелец репозитория.
- **Затронутые контракты:** нет.

### 2026-10-25 — Удалена папка `Tests/`

- **Что изменено:** удалены черновые тексты `Tests/Text1–3`.
- **Почему:** это был простой текст без HTML-разметки, он не подходил ни для проверки извлечения, ни как фикстура. Проверочные страницы создаются заново в `fixtures/`.
- **Кто принял решение:** владелец репозитория.
- **Затронутые контракты:** нет.
