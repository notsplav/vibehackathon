# Фикстуры

- `pages/` — собственные синтетические страницы с разной разметкой (JSON-LD-массив, `@graph`, без JSON-LD, повреждённый JSON-LD, не статья). Контент написан командой, его можно коммитить.
- `expected/` — ожидаемый результат извлечения для каждого случая и источник страницы. Для чужих статей указаны только URL и дата сохранения.
- `local/` — локальные копии чужих статей (в `.gitignore`). Имя файла любое: тест находит копию по URL статьи внутри HTML. Вместо этого можно указать путь в `TEST_ARTICLE_HTML`.

Если локальной копии нет, соответствующий тест пропускается с пояснением.

После намеренного изменения алгоритма извлечения: `UPDATE_EXPECTED=1 npm test`, затем просмотрите дифф `fixtures/expected/` и закоммитьте только ожидаемые изменения.
